Пример ввода и результата - `5, 11, 123, 14, 1 -> 6 (5+1) -> 9 (6+3) -> 13 (9+4) -> 4 (3+1)`

### Алгоритм решения

Беру остатки от деления на 10 и убираю знак минус. В `main` сохраняю первое число в `sum`. Для каждого из следующих четырёх чисел снова вызываю метод и сохраняю результат в `sum`

```java
public int lastNumSum(int a, int b) {
    int digitA = Math.abs(a % 10);
    int digitB = Math.abs(b % 10);
    return digitA + digitB;
}
```

### Алгоритм решения

Записываю в `result` единицу. Цикл выполняется `y` раз и каждый раз умножает результат на `x`. При нулевой степени цикл не запускается

```java
public int pow(int x, int y) {
    int result = 1;
    for (int i = 0; i < y; i++) {
        result = Math.multiplyExact(result, x);
    }
    return result;
}
```

## Задача 6. Одинаковость

### Текст задачи

Дана сигнатура метода: `public boolean equalNum(int x)`

Проверить, одинаковы ли все цифры числа

Пример ввода и результата - `1111 -> true, 1211 -> false`

### Алгоритм решения

Запоминаю последнюю цифру через `% 10`. Делю число на 10, чтобы убрать уже проверенную цифру. Сравниваю остальные цифры с первой запомненной

```java
public boolean equalNum(int x) {
    int digit = x % 10;
    x = x / 10;
    while (x != 0) {
        if (x % 10 != digit) {
            return false;
        }
        x = x / 10;
    }
    return true;
}
```

```java
public void rightTriangle(int x) {
```

Дана сигнатура метода: `public int findLast(int[] arr, int x)`

Найти индекс последнего появления `x` в массиве. Если числа в массиве нет, вернуть `-1`

Пример ввода и результата - `[1, 2, 3, 4, 2, 2, 5], x = 2 -> 5`

### Алгоритм решения

Иду с конца массива к началу. Первое совпадение при таком обходе даёт индекс последнего вхождения

```java
public int findLast(int[] arr, int x) {
    for (int i = arr.length - 1; i >= 0; i--) {
        if (arr[i] == x) {
            return i;
        }
    }
    return -1;
}
```

## Задача 5. Добавление массива в массив

### Текст задачи

Дана сигнатура метода: `public int[] add(int[] arr, int[] ins, int pos)`

Вернуть новый массив со всеми элементами `arr`, вставив элементы `ins` с позиции `pos`

Пример ввода и результата - `[1, 2, 3, 4, 5], [7, 8, 9], pos = 3 -> [1, 2, 3, 7, 8, 9, 4, 5]`

### Алгоритм решения

Создаю новый массив длиной `arr.length + ins.length`. Копирую начало `arr` до позиции `pos`, затем весь `ins`, затем оставшуюся часть `arr`. Позиции считаю с нуля. Позиция `arr.length` означает вставку в конец.

```java
public int[] add(int[] arr, int[] ins, int pos) {
    int[] result = new int[arr.length + ins.length];
    for (int i = 0; i < pos; i++) {
        result[i] = arr[i];
    }
    for (int i = 0; i < ins.length; i++) {
        result[pos + i] = ins[i];
    }
    for (int i = pos; i < arr.length; i++) {
        result[i + ins.length] = arr[i];
    }
    return result;
}
```

## Задача 8. Объединение

### Текст задачи

Дана сигнатура метода: `public int[] concat(int[] arr1, int[] arr2)`

Вернуть новый массив, в котором за элементами первого массива идут элементы второго

Пример ввода и результата - `[1, 2, 3] и [7, 8, 9] -> [1, 2, 3, 7, 8, 9]`.

### Алгоритм решения

Создаю новый массив. Первым циклом записываю элементы `arr1`, вторым добавляю элементы `arr2`, начиная с позиции `arr1.length`

```java
public int[] concat(int[] arr1, int[] arr2) {
    int[] result = new int[arr1.length + arr2.length];
    for (int i = 0; i < arr1.length; i++) {
        result[i] = arr1[i];
    }
    for (int i = 0; i < arr2.length; i++) {
        result[arr1.length + i] = arr2[i];
    }
    return result;
}
```

## Задача 10. Удалить негатив

### Текст задачи

Дана сигнатура метода: `public int[] deleteNegative(int[] arr)`

Вернуть новый массив без отрицательных элементов

Пример ввода и результата - `[1, 2, -3, 4, -2, 2, -5] -> [1, 2, 4, 2]`

### Алгоритм решения

Первым проходом считаю числа больше или равные нулю. Создаю массив нужной длины. Вторым проходом копирую в него подходящие числа

```java
public int[] deleteNegative(int[] arr) {
    int count = 0;
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] >= 0) {
            count++;
        }
    }

    int[] result = new int[count];
    int j = 0;
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] >= 0) {
            result[j] = arr[i];
            j++;
        }
    }
    return result;
}
```
